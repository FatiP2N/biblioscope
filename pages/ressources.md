# Ressources

Cette page est un exemple d'onglet ajouté sans toucher au code. Modifiez-la librement :
le texte s'écrit simplement, en **Markdown**.

## Liens utiles

- [OpenAlex](https://openalex.org) : base ouverte de publications scientifiques
- [Espacenet](https://worldwide.espacenet.com) : recherche de brevets de l'OEB
- [Publish or Perish](https://harzing.com/resources/publish-or-perish) : logiciel gratuit d'analyse de citations

## Exemple de contenu intégré (code embed)

Collez ici n'importe quel code « embed » ou « intégrer » copié depuis YouTube, Google Forms,
Google Maps, Flourish, Datawrapper… Pour une vidéo qui s'adapte à l'écran, entourez-la de
`<div class="embed">` et `</div>` :

<div class="embed">
<iframe src="https://www.openstreetmap.org/export/embed.html?bbox=-17.5%2C20.5%2C-0.9%2C36.0&amp;layer=mapnik" title="Carte du Maroc"></iframe>
</div>

> Astuce : laissez une ligne vide avant et après chaque code embed.
