# Resources

This page is an example of a tab added without touching the code. Edit it freely:
text is written simply, in **Markdown**.

## Useful links

- [OpenAlex](https://openalex.org): open database of scholarly works
- [Espacenet](https://worldwide.espacenet.com): EPO patent search
- [Publish or Perish](https://harzing.com/resources/publish-or-perish): free citation analysis software

## Embedded content example (embed code)

Paste any "embed" code copied from YouTube, Google Forms, Google Maps, Flourish, Datawrapper…
For a video that fits the screen, wrap it in `<div class="embed">` and `</div>`:

<div class="embed">
<iframe src="https://www.openstreetmap.org/export/embed.html?bbox=-17.5%2C20.5%2C-0.9%2C36.0&amp;layer=mapnik" title="Map of Morocco"></iframe>
</div>

> Tip: leave an empty line before and after each embed code.
